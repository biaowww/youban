## 1. 产品定义

**问题**：3A 游戏主线动辄 15–30 小时，时间有限的玩家门槛过高、容易半途而废，且缺乏"我在哪、还剩多少"的直观感。

**定位**：一个**游戏进度陪伴**应用 —— 像看进度条一样掌握整个旅程：进度可视化、剧情高潮标注、Boss 跳关辅助、玩家舆情参考。面向中国市场本地化。

**目标用户**：时间有限但想完整体验 3A 剧情的玩家；偏好"效率游玩"、二周目速通、或先看进度再决定是否入坑的人。

## 2. 当前状态（2026-06-21）

- **游戏库**：5 款 —— Star Wars Jedi: Fallen Order / 黑神话·悟空 / Max Payne 3 / The Last of Us I & II。
- **新 UI 已落地**：Off-Circle 品牌（金色 ⊙ 标识，暖墨底），手机端 React 组件；开屏 → 登录 → 游戏库 → 进度/历程/舆情三 Tab + 各抽屉。
- **跨端工程**：`electron` 分支（本地测试基准）+ `tauri` 分支（v2，正式 release，PC/iOS）；微信小程序为独立端。数据加载**环境自适应**（Tauri invoke / Electron IPC / 浏览器）。
- **工程化**：游戏数据 = `src/data/games/*.json` 经 `adaptGame` 适配；JSX 预编译为 `dist/`，本地 vendored React，字体/封面已本地化（离线、国内秒开）；Vitest+jsdom 测试体系（schema 校验 + 适配器 + 全屏渲染，约 102 用例）；Steam 成就→进度**纯逻辑引擎**（含 Mock 客户端，未接真实 Key）。

## 3. 核心功能

- **进度可视化**：水平进度条 + Hype Wave 热度波形（剧情张力曲线），标注章节节点、Boss 战、剧情高潮、关键人物登场。
- **进度输入（三级）**：① 手动选章节（已实现）；② Steam 成就自动定位（引擎已就绪，待接真后端）；③ 截图 AI 识别（Claude Vision，后期）。
- **Boss 跳关面板**：剧情/人物/战斗/存档四 Tab + 跳关补课难度；部分游戏含社区存档下载。
- **主角成长历程 / 玩家舆情**：能力解锁时间轴；Steam 好评率 + 引用 + 关键词。
- **入场点推荐**：「只有 X 小时从这里开始」。
- **主题**：浅色（默认）/ 游戏主题色（每款专属配色）。

## 4. 跨端架构

天然分三块（详见 `架构方案-Tauri迁移与登录授权.md`）：

- **A：PC + iPhone（+Android）** → Tauri v2，复用同一套 web 前端。
- **B：微信小程序** → 独立运行时（Taro 或手写降级版），Tauri 覆盖不到。
- **C：公共后端 BFF** → 三端共用，托管密钥、登录授权、聚合数据（见第 5 节）。

## 5. 数据与后端（v0.3 核心新增）

**为什么必须线上化**：

1. **跨端共享**：游戏数据要供 PC / iOS / 小程序三端共用，不能各端塞一份本地 JSON。
2. **服务端维护内容**：游戏数据放线上 DB 后，新增/修订游戏**不必发版**，服务端改即可。
3. **账号系统**：用户登录 + 进度**云端存储 + 多端同步**，需要数据库。
4. **平台授权**：Steam 的 Web API Key、各平台 OAuth secret **绝不能进前端/小程序**，必须服务端持有。

**技术选型（拟）：自托管 Supabase 部署在腾讯云**。Supabase = Postgres 数据库 + Auth 账号 + 自动 REST/Realtime API + Storage，正好覆盖"游戏数据 + 用户账号 + 文件"。两种用法对比：

| 维度 | Supabase Cloud（官方托管） | **自托管在腾讯云（推荐）** |
|---|---|---|
| 部署 | 注册即用、零运维 | Docker 自部署，需运维（备份/更新/HTTPS） |
| 国内延迟 | 高（700ms+，海外机房） | **低（REST 50–100ms）** |
| 微信小程序 | ❌ 域名未 ICP 备案，进不了 request 白名单 | ✅ 用自己**已备案**的域名，小程序可调 |
| 适用 | 快速原型 / 海外 | **国内 + 小程序正式上线** |

**结论**：因为要做**微信小程序 + 国内用户**，自托管 Supabase 在腾讯云是对的路（你的直觉正确）。关键前置：一台腾讯云服务器（≥2C4G）+ Docker + 一个**已 ICP 备案的域名**（小程序后端必须备案，新域名备案后需 24h 才能配；不能用 IP）。

**分期落地**：本地 JSON（现状）→ 线上 DB（先服务 PC/iOS，可先用 Cloud 快速起步）→ **小程序上线前必须迁到腾讯云自托管 + 备案域名**。客户端保留本地缓存以离线可用。

## 8. 合规与风险

- 纯外部伴侣工具，**不注入游戏进程、不改内存**；存档替换在游戏关闭时操作 —— 不触发反作弊封号。
- Steam Web API 走服务端、有速率上限（个人远低于上限）；用户资料需公开才能读成就。
- 攻略数据仅用于个人工具、非商业再发布；社区存档标注来源。
- 账号/隐私：面向中国市场需符合《个人信息保护法》，token 加密存储、最小化收集、提供解绑与数据删除。
