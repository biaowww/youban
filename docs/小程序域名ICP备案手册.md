# 小程序域名 ICP 备案手册（游伴 · 腾讯云企业备案）

> 2026-07 按官方现行流程整理（来源附文末）。**两件事都要办**：① 后端域名的 **ICP 备案**（腾讯云）；② **小程序本体备案**（微信公众平台，2023-09 起不备案不能上架）。备案全程免费，花钱的只有域名和服务器。

## 先看关键结论（针对我们的情况）

1. **必须等新营业执照**。公司改名+地址变更正在办——备案主体信息必须与工商登记**完全一致**，且**提交管局后信息无法中途变更**，用旧执照抢跑大概率被驳回重来（管局审 11-12 个工作日，期间工商数据一变就废）。→ **新执照到手是整个链条的起点**。
2. **但域名现在就能买**（并行优化）：企业备案的域名所有者可以是**企业名称或法定代表人**。改名不改法人 → **现在就用法人（王彪）个人实名买好域名**，不受改名影响，还把 72 小时实名入库等待期提前消化掉。
3. **后缀有坑：`.app` / `.dev` / `.io` 不在工信部批复清单，不能备案**（= 不能用作小程序域名）。选 **`.com` / `.cn` / `.net`**。
4. **服务器地域决定能否出备案授权码**：只有**中国大陆**地域的 CVM/轻量服务器（包年包月 ≥3 个月、剩余 ≥1 个月）可以。offcircle-cloud 若是香港地域则不行——需另购一台大陆轻量（最低配即可，几十元/月，仅为备案资质+跑服务）。**SSH 通了我第一时间确认地域**。
5. **现实总时长**：新执照到手后，全链条约 **3-5 周**（ICP 四川管局约 11-12 个工作日 + 小程序备案 1-20 个工作日 + 公安备案）。所以执照一到就启动。

## 流程总览

```
[现在可做]                 [新执照到手后]                        [备案通过后]
买域名(.com/.cn)          ICP备案提交(腾讯云)                   公安备案(30日内)
法人实名认证       ──►     初审1-2工作日→短信核验24h      ──►    小程序本体备案(微信后台)
等72h实名入库             →四川管局约11-12工作日                 小程序后台配置request域名
确认服务器地域                                                  nginx挂域名+TLS→上线
```

## 第 1 步 · 买域名（现在就做）

- 在**境内注册商**买（推荐直接腾讯云 DNSPod，后续备案同平台省事；境外注册商的域名要先转入才能备案）。
- 后缀：**`.com` 首选，`.cn` 次之**。⚠️ 别买 `.app`/`.dev`/`.io`。
- **实名认证**：用**法定代表人**身份实名（不受公司改名影响）；完成后**至少等 72 小时**（实名信息入库工信部）才能提备案。
- 规划：一个主域名足够——后端统一走 `api.<域名>`，小程序 request 合法域名**每月只能改 5 次**，别频繁折腾。

## 第 2 步 · 服务器资质（等 SSH 确认）

- 合格条件：腾讯云 **CVM 或轻量应用服务器**、**中国大陆地域**、**包年包月且实际购买 ≥3 个月**、备案期间**剩余有效期 ≥1 个月**、有独立公网 IP。
- 服务器在自己企业实名的腾讯云账号下 → 直接备案；跨账号则生成**备案授权码**（控制台 → ICP 备案 → 授权码管理；CVM 最多 5 个/台，轻量 2 个/台）。
- ⚠️ 大陆服务器上，**未备案域名的 80/443 会被阻断**——备案下来前，开发用 `IP:端口` 或 SSH 隧道访问（后端部署计划已按此安排）。

## 第 3 步 · ICP 备案提交（新执照到手后）

**入口**：console.cloud.tencent.com/beian

**材料清单**（提前备齐）：
- **新营业执照**原件彩色照片（系统 OCR 识别，名称/信用代码/住所必须与工商登记一致）
- **法定代表人身份证**人像面 + 国徽面
- 负责人**大陆手机号 + 应急电话 + 邮箱**；通信地址精确到门牌号
- 网站信息：服务名称（如"游伴"）、域名、服务内容描述、云资源（服务器/授权码）
- 域名实名认证信息截图

**真实性核验**：幕布拍照已淘汰——现在是**微信扫码人脸视频核身**（+86 手机号注册的微信、纯白背景、可能要朗读指定文字、需授权 GPS；二维码 30 分钟有效）。

**流程与时长**：腾讯云初审 **1-2 个工作日**（审核员会来电核对）→ **工信部短信核验**（收到后 24 小时内点确认，别漏！）→ 提交管局 → **四川管局约 11-12 个工作日**（法定上限 20 个）。**提交管局后信息不可改**，一次填对。

## 第 4 步 · 备案通过后的义务

- **公安联网备案**：通过后 **30 日内**在 beian.mps.gov.cn 办理。我们是"小程序/API"形态——该平台已支持按**小程序类型**备案；纯 API 域名是否可免"网站类"公安备案无成文规定（**待核**，稳妥做法：在 `api.<域名>` 根路径放一个含备案号的简单页面，并咨询当地网安）。
- **悬挂备案号**：网页底部标 ICP 备案号并链接 beian.miit.gov.cn。

## 第 5 步 · 小程序本体备案（独立的一道，别漏）

- **2023-09 起新小程序必须备案后才能上架发布**。
- 入口：mp.weixin.qq.com → **设置 → 小程序备案**。
- 材料与 ICP 类似（新营业执照、法人证件、负责人证件、人脸核验），主体信息与 ICP 系统联动可复用。
- 时长：平台初审 1-2 个工作日 → 短信核验 24h → 通管局 **1-20 个工作日**。
- 建议：**ICP 域名备案下来后紧接着提**（也可尝试并行，以平台提示为准）。

## 第 6 步 · 小程序后台配置服务器域名

mp.weixin.qq.com → 开发管理 → 开发设置 → **服务器域名**：
- 只能填 **https**（TLS ≥1.2，iOS 不认自签证书 → 用 certbot/Let's Encrypt 正规证书）；
- **不能填 IP / localhost**；URL 里**别写端口**（配置时没带端口的话，连 `:443` 都不能出现在请求里）；
- **每月限改 5 次**；新备案域名约需 24h 同步后才配得上（待核）。
